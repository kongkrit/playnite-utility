What is this page?

It gives many games the same Completion Status or the same tag, or hides them, in a few clicks, then saves the result as a new CSV. The Filter tab instead splits the games into two CSVs. It runs only in this browser; nothing is uploaded. Games whose Hidden is True are left out of Filter unless Include hidden is ticked.

  1. Drop a Playnite export (from Library Exporter Advanced) on the box.
  2. Pick the Target Completion Status.
  3. Type the tag under Apply Tag.
  4. Hidden games are on the right. Tag: narrows the left list to games whose tags contain the text.
  5. Set any of Filter by status, Source:, Filter by name and Tag:. Games that pass all of them are MATCHED, on the right; empty filters match everything. The rest are Unmatched.
  6. Games whose Hidden is True are left out of both lists and both exports. Tick Include hidden to include them.
  7. Click Export unmatched or Export matched to download games-unmatched_YYYYMMDD_HHMM.csv or games-matched_YYYYMMDD_HHMM.csv, with every column of the dropped file. Nothing changes in Playnite, so there is no script.
  8. Narrow both lists with Filter by name and Source:. Filter by status narrows only the left list.
  9. Show all can narrow both lists to hidden or not hidden games.
  10. Click a game on the left to mark it. Click a game on the right to undo a mark you made or un-hide it, even if it was hidden in the file. Changed games are highlighted.
  11. Click Export .csv to download games-statustaghide_YYYYMMDD_HHMM.csv.

Import it back into Playnite

Playnite cannot import a CSV, so a short script in Playnite's built-in PowerShell console applies the changes instead. The script below applies what you tick in step 4.

  1. Optional: copy your Playnite folder first, so you can undo. The portable version keeps its whole database in that folder.
  2. In Playnite's main menu, open Extensions > Interactive SDK PowerShell.
  3. Right away, press Ctrl+V then Enter in the console. When the console opens, Playnite puts commands on the clipboard that load $PlayniteApi, the script's link to your library. Do this before you copy the script, because copying replaces those commands. If they're gone, close the console and open it again.
  4. Under Import from, pick current content to apply the games as this page shows them, with no export, or a .csv to apply a file you exported. Fill in the boxes below, then click Copy, paste the script into the console, and press Enter. For a .csv, get the path by right-clicking the file in File Explorer and choosing Copy as path (Windows 10: Shift+right-click).
